# Dataset

Download `WA_Fn-UseC_-Telco-Customer-Churn.csv` from the [BlastChar Telco Customer Churn dataset on Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) and place it in this folder. Kaggle sign-in may be required. The app expects the original CSV (7,043 customers, 21 columns) and does not alter the source file.
